With Screen Recording allowed, Sheer now checks which image of a Dynamic wallpaper the desktop really shows, so the menu bar stays in step even when macOS doesn't follow its own rules (for example right after location or the time zone changes).
---
如果允许了屏幕录制，Sheer 现在会核对桌面实际显示的是动态壁纸的哪一张，即使 macOS 没按自己的规则换图（比如刚关掉定位或刚改时区），菜单栏也能和桌面保持一致。
---
Unzip, move Sheer.app to Applications, then open it. The first time, allow it under System Settings → Privacy & Security → Open Anyway.
