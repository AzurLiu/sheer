With a Dynamic wallpaper, Sheer no longer records the screen to follow it. It learns the moment of each change from macOS's own record, and sees which image the desktop shows by reading the wallpaper's own window, which macOS doesn't count as screen recording. It also stays with the desktop when macOS is slow to show the new image, as can happen with an app in full screen.
---
使用动态壁纸时，Sheer 不再靠录屏来跟随换图。换图时刻取自 macOS 自己的记录；桌面实际显示哪一张，则直接读壁纸自己的窗口，macOS 不把这算作屏幕录制。有应用全屏时 macOS 有时会迟迟不显示新图，这种情况下 Sheer 也会和桌面保持一致。
---
Open Sheer.dmg and drag Sheer onto Applications, then open it. The first time, allow it under System Settings → Privacy & Security → Open Anyway.
