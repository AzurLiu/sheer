Sheer now also runs on macOS 12.3 Monterey and macOS 13 Ventura. This is experimental: it builds and runs the same code on macOS 14 and 15 as before, but hasn't been tested on 12 or 13 yet. If something looks off there, please open an issue with your macOS version and a screenshot of the menu bar. If Sheer can't find the menu bar there, it is designed to step aside and leave the normal menu bar showing. On macOS 12, Launch at Login isn't available from Sheer's menu; add it under System Preferences → Users & Groups → Login Items.
---
Sheer 现在也能在 macOS 12.3 Monterey 和 macOS 13 Ventura 上运行。这是实验性支持：macOS 14 和 15 上的行为和以前一样，但还没在 12 或 13 上实测过。如果显示不对，请提交 issue，附上系统版本和菜单栏截图。如果 Sheer 在那里找不到菜单栏，按设计它会自动让开，显示系统原本的菜单栏。在 macOS 12 上，Sheer 菜单里没有"登录时启动"，请在"系统偏好设置 → 用户与群组 → 登录项"里添加。

Unzip, move Sheer.app to Applications, then open it. The first time, allow it under System Settings → Privacy & Security → Open Anyway.
